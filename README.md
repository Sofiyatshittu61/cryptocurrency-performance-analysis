# cryptocurrency-performance-analysis
My beginner data analysis project comparing cryptocurrency performance and volatility
## Project Overview
This is a beginner data analysis project that compares the performance of selected cryptocurrencies over a one-year period.
## Research Question

Which major cryptocurrencies performed best over the past year based on their returns and volatility?

## Objective

To analyze and compare the historical performance and price volatility of selected cryptocurrencies.

## Data Elements

- Cryptocurrency name
- Date
- Opening price
- Closing price
- Highest price
- Lowest price
- Trading volume
- Market capitalization
- Return
- Volatility

## Tools

- Microsoft Excel
- GitHub
